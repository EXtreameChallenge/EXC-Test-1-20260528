# 德莫 - 无人车队管理系统 PC端后台管理界面

## 设计规范文档 v1.0

---

## 一、项目概述与设计愿景

### 1.1 产品定位

德莫 PC 端后台管理系统是无人车队智能调度运营平台的管理中枢，专为运营管理人员设计，提供车队监控、数据分析、调度管理、配置运营等一站式管理能力。

**核心价值主张**：让管理者在一个界面中掌控全局，告别多系统切换的繁琐。

### 1.2 设计愿景

- **专业感**：深色科技风格，契合智能驾驶/AI 的未来感
- **高效性**：信息密度高但不拥挤，重要数据一目了然
- **易用性**：符合传统后台管理操作习惯，学习成本低
- **智能感**：融入 AI 能力，提供智能辅助决策

### 1.3 设计语言继承

PC 端必须与移动端保持视觉一致性：

| 设计要素 | 移动端现有风格 | PC 端继承方案 |
|---------|--------------|--------------|
| 主色调 | `#0a0a1a` 深色背景 | 保持一致 |
| 强调色 | 蓝色 `#4a9eff`、紫色 `#c084fc` | 保持一致 |
| 状态色 | 绿/蓝/橙/红 | 保持一致 |
| 字体 | 系统字体栈 (SF Pro / Noto Sans SC) | 保持一致 |
| 圆角风格 | 12-20px 大圆角 | 保持一致 |
| 毛玻璃效果 | `backdrop-filter: blur()` | 保持一致 |

### 2.4 组件样式规范

**按钮**：
- 主按钮：渐变 `#4a9eff → #6366f1`，白色文字，12px 圆角
- 次按钮：玻璃背景 `rgba(255,255,255,0.08)`，边框 `rgba(255,255,255,0.1)`
- 危险按钮：渐变 `#f87171 → #ef4444`
- 禁用态：`opacity: 0.4`，`cursor: not-allowed`

**卡片**：
- 背景：`rgba(255,255,255,0.08)` 毛玻璃
- 边框：`0.5px solid rgba(255,255,255,0.15)`
- 圆角：16-20px
- 内阴影：`inset 0 1px 0 rgba(255,255,255,0.08)`
- 外阴影：`0 2px 8px rgba(0,0,0,0.2)`

**表格**：
- 表头：背景 `#1a1a3a`，文字 `--text-secondary`
- 行悬停：`background: rgba(255,255,255,0.04)`
- 行高：48px
- 边框：`0.5px solid rgba(255,255,255,0.06)`

**表单输入**：
- 背景：`rgba(255,255,255,0.06)`
- 边框：`0.5px solid rgba(255,255,255,0.1)`
- 聚焦态：边框变 `--accent-blue`，加发光效果

## 五、交互规范

### 5.1 通用交互原则

1. **一致性**：同类操作有相同的交互模式和视觉反馈
2. **即时反馈**：每个操作都有明确的成功/失败反馈
3. **可逆性**：危险操作（如删除）提供确认，且支持撤销
4. **渐进披露**：复杂功能分层展示，不一次暴露所有选项

### 5.2 操作反馈规范

| 操作类型 | 反馈方式 |
|---------|---------|
| 操作成功 | Toast 提示 + 数据列表刷新 |
| 操作失败 | Toast 错误提示 + 错误详情 |
| 删除操作 | 二次确认弹窗 + 成功后 Toast |
| 批量操作 | 进度条 + 结果统计 |
| 加载中 | 按钮 loading 态 + 全局遮罩（可选） |

### 5.3 快捷键支持

| 快捷键 | 功能 |
|-------|------|
| `Ctrl + F` | 全局搜索 |
| `Ctrl + N` | 新建任务 |
| `Ctrl + R` | 刷新当前页面 |
| `Escape` | 关闭弹窗/取消操作 |
