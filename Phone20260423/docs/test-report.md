## 三、详细测试用例

### T1-T2: 页面基础
- 输入：访问 http://localhost:3000
- 预期：页面正常加载，底部导航可切换
- 检查项：
  - [ ] 页面无 JS 错误
  - [ ] CSS 样式正常应用
  - [ ] 三个 Tab 可切换

### T3-T6: 语音输入
- 输入：点击麦克风图标
- 预期：弹出语音模态框
- 检查项：
  - [ ] 模态框显示
  - [ ] 点击"开始"进入录音状态
  - [ ] 录音动画（脉冲效果）
  - [ ] 2-3.5 秒后自动停止
  - [ ] 随机选择方言并显示
  - [ ] 识别完成后自动发送指令

### T7: 场景推荐
- 输入：打开对话 Tab
- 预期：快捷操作区显示场景推荐
- 检查项：
  - [ ] 当前时段推荐芯片显示
  - [ ] 点击推荐可发送对应指令

### T8-T9: 安全验证
- 输入：点击确认执行按钮
- 预期：弹出安全验证弹窗
- 检查项：
  - [ ] 弹窗显示四重验证信息
  - [ ] 每项验证有图标和文字说明
  - [ ] 点击确认后执行操作

### T10: 权限管理
- 输入：查看页面 Header
- 预期：显示"运营管理员"权限徽章
- 检查项：
  - [ ] 徽章样式正确
  - [ ] 无文本泄露

### T11-T12: 批量操作
- 输入：输入"批量充电"
- 预期：显示批量操作面板
- 检查项：
  - [ ] 低电量车辆列表显示
  - [ ] 批量按钮可点击
  - [ ] 点击后车辆状态更新

### T13: 车队状态
- 输入：切换到"车队" Tab
- 预期：12 辆车正常显示
- 检查项：
  - [ ] 车辆卡片渲染正常
  - [ ] 状态颜色正确
  - [ ] 电量显示正常

### T14: AI 对话
- 输入：发送指令
- 预期：AI 正常回复
- 检查项：
  - [ ] 用户消息显示
  - [ ] AI 回复内容正确
  - [ ] 加载动画正常
